## Statement

The system shall let the user record, for each individual set of each exercise in today's workout and
at the moment it is performed, the reps actually completed and the weight actually used together with
the unit that weight is expressed in, and shall let any set already recorded in that workout be
corrected without disturbing the other sets of the same exercise.

## Rationale

The owner's second statement is the whole of this record: "the user is able to save the amount of
sequences and reps, and also their weights per sequence". The load-bearing word is *per* — weight is a
property of the individual set, not of the exercise, because a working set is normally heavier than
the warm-up sets above it in the same list, and progression is read off the per-set numbers. A model
that stored one weight per exercise would satisfy a casual reading of the sentence and be useless in
the gym. Two further properties come from the setting rather than from the sentence: entry happens
between sets, one-handed, so it cannot demand navigation away from REQ-FR-260003's screen; and what
was performed routinely differs from what was planned — an extra set, a dropped set, a lighter day —
so the log records what happened, and the plan is a target it is measured against, never a schema it
must satisfy. What the recorded sets look like in Crystord is ADR-260001's subject, not this record's.

## Acceptance Criteria (behavioral)

- End-to-end: recording set 1 as 8 reps at 60 and set 2 as 8 reps at 65 for one exercise, then
  reloading the app, reads both sets back in order with their own reps and their own weight.
- End-to-end: a weight unit is recorded with the log and shown beside every weight; a workout logged
  in kilograms reads back in kilograms on a device whose locale would otherwise imply pounds.
- End-to-end: logging a fourth set against a three-set plan is accepted and read back, and so is
  logging only two; neither is blocked, coerced to the planned count, or silently dropped.
- End-to-end: a weight of zero (bodyweight) and a fractional weight (a 2.5 increment) are both
  accepted and read back exactly, not rounded, blanked, or rejected as invalid.
- End-to-end: correcting a recorded set's reps or weight changes that set only — every other set of
  the same exercise reads back unchanged, and the corrected value survives a reload.
- End-to-end: entering a set requires no navigation away from today's workout screen and no
  re-selection of the exercise.
